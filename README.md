# Garika RP — Auth System

Собственная система авторизации для GTA San Andreas Multiplayer (SA-MP).

## Возможности
- Регистрация и вход игроков
- Собственный интерфейс авторизации
- Подключение к MySQL
- Интеграция с игровым лаунчером
- Безопасная проверка аккаунтов сервером

## Структура проекта
- client — клиентская часть авторизации
- server — серверная часть
- launcher — интеграция с лаунчером

## Статус
Проект находится в разработке.
